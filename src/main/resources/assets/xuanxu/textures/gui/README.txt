灵根 UI 贴图命名要求
====================

请将文件重命名为以下英文名，否则游戏内无法加载：

背景图：
- 古风背景.png          -> lingen_background.png

五行元素图标：
- 进元素重新绘制.png     -> element_gold.png
- 木元素重新绘制.png     -> element_wood.png
- 水元素重新绘制.png     -> element_water.png
- 火元素重新绘制.png     -> element_fire.png
- 土元素重新绘制.png     -> element_earth.png

注意：Minecraft 资源路径不支持中文文件名。
